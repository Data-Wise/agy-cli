# Tutorial 7 · R Package Harness

**Goal:** Use `agy rforge` to run `devtools::check`, `devtools::test`, and `devtools::document` directly from the CLI — without opening RStudio.

---

## Prerequisites

- R installed with `devtools` package: `install.packages("devtools")`
- A valid R package directory containing a `DESCRIPTION` file

---

## Step 1 — Compile Roxygen2 Documentation

Generate/update `.Rd` help files and `NAMESPACE` from `#'` comments:

```bash
agy rforge --pkg-dir ./my_r_package document
```

**R equivalent:** `devtools::document()`

Output:

```
Compiling Roxygen2 documentation...
✔ Documentation compiled successfully.
```

---

## Step 2 — Run Unit Tests

Execute the test suite in `tests/testthat/`:

```bash
agy rforge --pkg-dir ./my_r_package test
```

**R equivalent:** `devtools::test()`

Output on success:

```
Running package unit tests...
✔ Package unit tests passed.
── Test results ──────────────────────────────
[ PASS  7 ] test-dag_compiler.R
[ PASS  3 ] test-positivity.R
[ PASS  5 ] test-balance.R
```

---

## Step 3 — Check Package Integrity

Full CRAN-readiness check (skips re-documenting for speed):

```bash
agy rforge --pkg-dir ./my_r_package check
```

**R equivalent:** `devtools::check(document = FALSE)`

Output:

```
Running package check...
✔ Package check passed successfully.
```

!!! warning "Check failures"
    If `check` fails, look at `stderr` for `ERROR:` or `WARNING:` lines.
    Common causes: missing `Imports` in `DESCRIPTION`, undocumented exported functions, or test failures.

---

## Step 4 — Full Validation Pipeline

Chain all three in sequence for a complete validation run:

```bash
agy rforge --pkg-dir ./my_r_package document && \
agy rforge --pkg-dir ./my_r_package test && \
agy rforge --pkg-dir ./my_r_package check
```

---

## Recommended Package Structure

```text
my_r_package/
├── DESCRIPTION         ← Required: metadata, version, dependencies
├── NAMESPACE           ← Auto-generated by document
├── R/
│   └── functions.R     ← Source with roxygen2 comments
└── tests/
    ├── testthat.R      ← Test runner entry point
    └── testthat/
        └── test-func.R ← Individual test files
```
