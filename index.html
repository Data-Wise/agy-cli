    agy-cli

    Core workflow engine for Antigravity (Gemini CLI) — optimized for causal inference research, Obsidian/Atlas vault management, and R ↔ Python interop.

    🎯 BLUF

    Property Value
    Startup \(T < 10\text{ms}\) — entirely in-process
    Assumptions Auto-verifies Positivity, Backdoor Exchangeability, SUTVA
    Plugins Local SQLite Obsidian graphs & Atlas session files
    Sandbox Generates dummy vaults/CSVs for validation testing

    ⚡ Quick Start

    brew tap data-wise/tap
brew install agy
agy status

    git clone git@github.com:Data-Wise/agy-cli.git
cd agy-cli
uv sync --all-extras
uv run agy status

    🧩 Core Commands

    • Assumptions Eval

      Verify Positivity, Exchangeability, and SUTVA from a YAML study design.

      agy eval study_design.yaml

    • DAG Compiler

      Compile edge notation to ggdag/dagitty R code.

      agy dag "W -> Y, X -> W, X -> Y" \
    -t W -y Y -o dag.R

    • Covariate Balance

      Calculate SMD and generate balance tables.

      agy balance data.csv --treatment T \
    --covariates age sex income

    • Sandbox Vault

      Generate test Obsidian vaults with injected violations.

      agy sandbox generate ./test-vault \
    --violations

    📐 Causal Framework

    The engine enforces the three canonical identification assumptions:

    1. Positivity (Overlap)

    \[0 < P(W = w \mid X = x) < 1 \quad \forall\, x \in \mathcal{X},\; w \in \mathcal{W}\]

    2. Backdoor Exchangeability (Unconfoundedness)

    \[Y(w) \perp\!\!\!\perp W \mid X\]

    3. SUTVA

    \[Y_i(W) = Y_i(W_i) \quad \forall\, i\]

    The Average Treatment Effect (ATE) is identifiable when all three hold:

    \[\tau_{\text{ATE}} = \mathbb{E}[Y(1) - Y(0)] = \mathbb{E}_X\!\left[\mathbb{E}[Y \mid W=1, X] - \mathbb{E}[Y \mid W=0, X]\right]\]
